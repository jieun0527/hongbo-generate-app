# 홍보물 자동 만들기

매장 사진과 가게 정보만 넣으면, 인스타그램용 사진과 채널별 홍보 문구를 한 번에 만들어 주는 프로그램입니다.

## 웹에서 바로 쓰기

설치 없이 브라우저에서 바로 쓸 수 있는 웹 버전이 있습니다.

- 주소: https://jieun0527.github.io/hongbo-generate-app/
- 사진을 올리고 가게 정보를 확인한 뒤 "홍보물 만들기"를 누르면, 인스타용 사진과 인스타·블로그·카카오톡 문구가 나옵니다.
- 사진은 브라우저 안에서만 처리되고 어디로도 전송되지 않습니다.
- 파일: `index.html`(앱 본체), `logo.png`(기본 로고)

아래 설명은 컴퓨터에 설치해서 쓰는 파이썬 버전입니다.

## 하는 일

1. **사진 변환**: `자료` 폴더의 jpg, png 사진을 인스타그램용 1080 x 1080 정사각형으로 바꿉니다.
   - 사진 가운데를 기준으로 잘라서 찌그러지지 않습니다.
   - 오른쪽 아래에 로고를 흰색 반투명 동그라미 위에 작게 넣습니다. (로고 파일이 없으면 이 단계는 건너뜁니다.)
2. **홍보 문구 생성**: `자료\가게 정보.txt`를 읽어서 아래 세 가지를 만듭니다.
   - 인스타그램용 3가지 (감성형 / 정보형 / 이벤트형) + 해시태그 10개
   - 네이버 블로그용 (제목 + 본문 + 해시태그 12개)
   - 카카오톡 단골 공지용 (3줄, 존댓말)
   - 말투는 사장님이 직접 쓴 글처럼 담백한 "~습니다" 체로 맞췄습니다.
3. **지난 결과 정리**: 실행할 때마다 `완성`에 있던 지난번 사진을 `완성\이전파일\날짜_시간` 폴더로 옮기고, 새 결과를 만듭니다.

원본 사진(`자료` 폴더)은 읽기만 하고 바꾸지 않습니다.

## 폴더 구성

```
홍보자동화/
├── 인스타변환.py        # 프로그램 본체
├── 실행.bat             # 더블클릭하면 실행되는 파일
├── 브릿지.ico           # 바탕화면 바로가기용 아이콘
├── 사용설명서.txt       # 비개발자용 사용 설명서
├── 자료/                # 넣어 주는 곳
│   ├── (매장 사진 jpg, png)
│   ├── 가게 정보.txt    # 가게 소개와 이번 주 홍보 내용
│   └── 로고.png         # 사진에 넣을 로고
└── 완성/                # 결과가 저장되는 곳
    ├── 오늘날짜_01.jpg ...
    ├── 홍보문구.txt
    └── 이전파일/날짜_시간/   # 지난번 사진 보관
```

## 사용 방법

1. `자료` 폴더에 이번 주 사진을 넣습니다.
2. `자료\가게 정보.txt`의 "이번 주 홍보할 것:" 아래 내용을 이번 주에 맞게 바꿉니다.
3. `실행.bat`을 더블클릭하거나, PowerShell에서 아래처럼 실행합니다.

   ```powershell
   python 인스타변환.py
   ```

4. `완성` 폴더에서 사진과 `홍보문구.txt`를 확인합니다.

자세한 순서는 [사용설명서.txt](사용설명서.txt)를 보세요.

### `가게 정보.txt` 작성 예시

```
가게 이름: 브릿지 커피
위치: 광주 북구 비엔날레 지구
가게 특징: 직접 로스팅하는 스페셜티 커피, 조용한 1인 좌석 많음
주 고객층: 30~40대 직장인, 근처 사무실 손님

이번 주 홍보할 것:
- 신메뉴 '흑임자 라떼' 5,500원, 국산 흑임자를 직접 갈아서 넣음, 고소하고 달지 않음
- 오전 11시 이전 방문 시 아메리카노 500원 할인
```

- 신메뉴는 한 줄만 쓰고, 이름을 작은따옴표 `'...'`로 감쌉니다.
- 혜택 줄에는 "할인" 같은 글자를 넣습니다.

## 필요한 것

- Python 3.12 이상
- Pillow (`pip install Pillow`)

## 주의할 점

- `홍보문구.txt`는 실행할 때마다 새로 덮어씁니다. 지난 문구를 남기려면 미리 복사해 두세요.
- `자료` 폴더의 사진은 그대로 남아 있어서, 실행할 때마다 다시 변환됩니다. 새 사진만 쓰려면 지난 사진을 `자료`에서 빼 주세요.
- 이름이 `로고`로 시작하는 파일은 사진으로 변환하지 않고 로고로만 사용합니다.
